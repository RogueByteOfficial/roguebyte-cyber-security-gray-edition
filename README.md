🌐 Overview | نظرة عامة
🇬🇧 English

RogueByte Cyber Lab is a full-stack cybersecurity education and hands-on skill evaluation platform designed for authorized security training, defensive operations, and practical security research.

The platform combines server-side mission validation, isolated lab environments, interactive terminal sessions, security telemetry, persistent data management, and a role-based administration system.

Featuring a modern Black Gray cybersecurity aesthetic with green accents, the interface supports both English (LTR) and Arabic (RTL), providing a responsive and localized user experience.

🇸🇦 العربية

RogueByte Cyber Lab هي منصة متكاملة لتعليم الأمن السيبراني وتقييم المهارات العملية، مصممة للتدريب الأمني المصرح به، والعمليات الدفاعية، والبحث الأمني التطبيقي.

تجمع المنصة بين التحقق من إنجاز المهام على الخادم، وبيئات التدريب المعزولة، والجلسات التفاعلية لسطر الأوامر، ومراقبة الأحداث الأمنية، وإدارة البيانات الدائمة، ونظام متكامل لإدارة المستخدمين والصلاحيات.

تعتمد المنصة هوية بصرية احترافية بألوان الأسود والرمادي ولمسات خضراء مستوحاة من عالم الأمن السيبراني، مع دعم كامل للغتين العربية والإنجليزية، واتجاهي العرض RTL وLTR، وتصميم متجاوب مع مختلف الشاشات.

🚀 Quick Start | البدء السريع
1. Prerequisites | المتطلبات الأساسية

تأكد من تثبيت الأدوات التالية قبل تشغيل المشروع:

Node.js v20.x أو v22.x LTS.
npm v10 أو إصدار أحدث.
Git.
Docker وDocker Compose عند استخدام النشر بالحاويات.
2. Installation | التثبيت والتشغيل

استنسخ المستودع وانتقل إلى مجلد المشروع:

# Clone the repository
git clone https://github.com/RogueByteOfficial/roguebyte-cyber-security-gray-edition.git

# Enter the project directory
cd roguebyte-cyber-security-gray-edition

# Install dependencies
npm install

# Start the development server
npm run dev


بعد تشغيل الخادم، افتح المتصفح على العنوان التالي:

http://localhost:3000

ملاحظة: يعتمد عنوان التشغيل وأوامر npm على إعدادات المشروع الفعلية.
3. Production Deployment | النشر الإنتاجي

لتشغيل المشروع باستخدام Docker Compose:

docker compose up -d --build


للتحقق من حالة الخدمة:

curl http://localhost:3000/api/health


قبل إتاحة المنصة للمستخدمين، تأكد من:

ضبط متغيرات البيئة والأسرار.
إعداد قاعدة البيانات الدائمة.
مراجعة إعدادات الشبكة وعزل الحاويات.
تفعيل المصادقة والصلاحيات المناسبة.
تعطيل حسابات العرض وتغيير بيانات الاعتماد الافتراضية.
مراجعة دليل النشر والإجراءات الأمنية.

⚖️ Responsible Use | الاستخدام المسؤول
🇬🇧 English

RogueByte Cyber Lab is intended for authorized cybersecurity education, defensive training, and controlled security research.

Users must never access, scan, or test systems without explicit authorization. All practical exercises should take place in isolated labs or on systems the user is legally authorized to test.
